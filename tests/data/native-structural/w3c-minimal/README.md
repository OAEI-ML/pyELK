# Synthetic OWL 2 cross-syntax fixture

These project-authored Apache-2.0 fixtures describe one structural ontology in Functional,
OWL/XML, RDF/XML, and Turtle syntax. They mirror pyowl-core's minimal W3C-production corpus so
the pyELK consumer suite remains self-contained while testing the frozen encoded-view handoff.
They are not copied from the W3C OWL Working Group test-suite export.
